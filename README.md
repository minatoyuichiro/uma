# uma — 競馬シミュレーター（合成データ）

**▶ https://minatoyuichiro.github.io/uma/**

スマホで遊べる競馬シミュレーターです。出走表を見て、各馬の勝率を予測し、3D の中継風の映像でレースを走らせます。

> ⚠️ **データはすべて合成（架空）です。** 馬名・騎手名・競馬場名・オッズ・レース結果は実在のものではありません。
> 予測は外れます。馬券の購入を勧めるものではありません。

## できること

- **レース**：開催予定のレース（36）と、結果の出ている過去のレース
- **予測**：過去の成績から推した各馬の強さで 5,000 回走らせた、勝つ確率・3 着以内の確率と、その内訳
- **3D**：熊本の地形・航空写真・建物に重ねた架空の「下通競馬場」で、実況（端末の読み上げ）つきで走らせる
- **データ一覧**：開催予定のレースの、過去の成績・条件別の成績・騎手・予測の数字（CSV も落とせます）
- **予測の当たり具合**：過去のレースで試した結果を「情報」タブに出しています

## 仕組み

サーバーは使っていません。合成データ・予測・3D の走りは、あらかじめ計算した JSON（`data/`）を読んでいます。
3D の走りは 1 レースにつき 6 通りあり、「もう一度走らせる」で切り替わります。
描画は [three.js](https://threejs.org)。
